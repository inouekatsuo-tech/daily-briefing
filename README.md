# 井上かつお SNS戦略プロジェクト

## 目的
X・Instagram・Threads・noteのフォロワー数と影響力を増やし、
その先にカナエルのDL数増加につなげる。

## パーソナルブランド
> 「バツ2・無一文から世界一周して43歳でFIREした男が、あなたの夢の叶え方を教える」

## フォルダ構成
```
sns-strategy/
├── planning/
│   └── SNS戦略管理.xlsx   ← メイン管理ファイル
├── posts/
│   ├── x/                 ← X投稿の下書き
│   ├── instagram/         ← Instagram投稿の下書き
│   ├── threads/           ← Threads投稿の下書き
│   └── note/              ← note記事の下書き
├── content/               ← 画像・素材など
├── assets/                ← ロゴ・プロフィール画像など
└── analytics/             ← 月次レポートなど
```

## 各SNSの役割
| SNS | 役割 | 投稿頻度 |
|-----|------|---------|
| X | 本音・拡散の起点 | 毎日2〜3投稿 |
| Instagram | ライフスタイル可視化・憧れ演出 | フィード週3＋ストーリーズ毎日 |
| Threads | 深い本音・実験場 | 週4〜5投稿 |
| note | 深掘り記事・資産コンテンツ | 週1〜2記事 |

## 2026年目標フォロワー数（年末）
- X: 1,050
- Instagram: 1,670
- Threads: 800
- note: 2,394
- **合計: 6,014**

## SNS → カナエル 誘導フロー
X/Instagram/Threads で「この人面白い」
→ noteで深く読んで「信頼できる」
→ 「SNSで夢叶えたい」気持ちが芽生える
→ カナエルDL・問い合わせ
